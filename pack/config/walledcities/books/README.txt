Walled Cities — personal bookshelf
==================================
Drop .txt files in this folder and they will appear as books
in city libraries, mixed in with the built-in collection.

File format (plain text, UTF-8):
  line 1: the book's title (31 characters shown at most)
  line 2: the author's name
  rest:   the text — blank lines make stanza/paragraph breaks.
          Long pages are split automatically.

Example (save as my_poem.txt):
  The Winter Road
  A. Traveler

  The road was white, the moon was thin,
  and no one knew the shape I'm in.

Files load when a world starts, so restart or reopen your
world after adding one. This README is ignored.
